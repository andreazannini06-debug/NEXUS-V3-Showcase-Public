# Disclosure Boundaries

This repository is a public description of an independent private project.

## Suitable for publication after review

- Non-sensitive descriptions of engineering goals
- Conceptual diagrams that do not reveal private interfaces or security mechanisms
- Verified, appropriately redacted results with explicit limitations
- Demonstrations developed separately for public release

## Excluded

- Original NEXUS V3 source code or private repository contents
- API keys, tokens, passwords, credentials, and secrets (including historical Git data)
- Private file paths, machine or user identifiers, and environment-specific configuration
- Raw terminal output, internal execution traces, privileged security details, or trust anchors
- Evidence or certification claims not independently checked against the original artifacts
- Third-party confidential material or code without publication rights

## Project boundaries

This showcase should not be used to infer that private implementations, security controls, or uncompleted development stages have been released, independently audited, or production-qualified.
